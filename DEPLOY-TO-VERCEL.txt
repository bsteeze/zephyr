Harmony of the Year — Vercel package

Files in this package:
- index.html
- harmony.css
- harmony-wheel.css
- harmony.js
- natal.css
- natal.js
- natal-engine.bundle.js

Deploy:
1. In Vercel, open the zephyr project.
2. Create a new deployment by uploading the entire extracted folder.
3. Confirm index.html is at the top level—not inside another nested folder.
4. Deploy to Production.
5. Under Project Settings > Domains, attach zephyr.guru and www.zephyr.guru.

No PHP runtime is required. All saved groups remain in the visitor's browser localStorage.
ZEPHYR EXPERT STORY ENGINE
==========================

Before deploying:

1. In Vercel, open Project Settings > Environment Variables.
2. Add OPENAI_API_KEY as a Sensitive variable for Production.
3. Do not place the key in this ZIP, GitHub, index.html, or browser JavaScript.
4. Deploy every file and folder in this package, including /api.
5. Redeploy after adding or rotating the environment variable.

The Expert Story Engine endpoint is:

  /api/interpret-chart
