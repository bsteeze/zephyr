Harmony of the Year — Vercel package

Files in this package:
- index.html
- harmony.css
- harmony-wheel.css
- harmony.js
- natal.css
- natal.js
- natal-engine.bundle.js
- pdf-export.js
- api/interpret-chart.js

Deploy:
1. In Vercel, open the zephyr project.
2. Create a new deployment by uploading the entire extracted folder.
3. Confirm index.html and the api folder are at the top level—not inside another nested folder.
4. Deploy to Production.
5. Under Project Settings > Domains, attach zephyr.guru and www.zephyr.guru.

No PHP runtime is required. Saved groups and natal profiles remain in the visitor's browser localStorage.
The Expert Story Engine requires OPENAI_API_KEY in Vercel Project Settings > Environment Variables.
Optional: set OPENAI_MODEL to override the default model.
